# Paróquia Santa Suzana - Site Oficial

Site oficial da Paróquia Santa Suzana com recursos de oração e rosários católicos.

## 📋 Sobre o Projeto

Este é um site estático em HTML que oferece:

- 🏛️ Página principal com informações da paróquia
- 🙏 Rosários católicos interativos
- 📖 Mistérios Gozosos, Luminosos, Dolorosos e Gloriosos
- 👤 Sistema de login e cadastro
- 📱 Design responsivo para todos os dispositivos

## 🎨 Tecnologias

- HTML5
- Tailwind CSS (via CDN)
- JavaScript Vanilla
- Google Fonts (Cormorant Garamond & Inter)

## 📱 Recursos

- Design responsivo mobile-first
- Navegação intuitiva entre mistérios
- Meditações completas para cada mistério
- Orações tradicionais do rosário
- Interface elegante e contemplativa
